# Figures

The final manuscript PDF figures are intentionally not bundled as authoritative experimental outputs because the qualitative figures must be generated from the actual model predictions and explanation maps.

Use:

- `scripts/generate_severe_fog_grid.py` for `severe_fog_results`.
- `scripts/generate_ecam_visualization.py` for `ecam_visualizations`.

The analytical plots can be regenerated directly using `scripts/reproduce_figures.py`.
